# FitSuite

FitSuite is a full-stack Gym Management System built to simplify gym operations, member management, memberships, plans, payments, and analytics through a modern dashboard.

## Live Demo

Live Application: https://fitsuitenow.vercel.app/

## Features

### Authentication

* Secure Login
* Role-Based Access Control
* Protected Routes

### Member Management

* Create Members
* Update Member Details
* Search Members
* Soft Delete Members
* Pagination Support

### Plan Management

* Create Plans
* Update Plans
* Delete Plans
* Manage Active and Inactive Plans

### Membership Management

* Assign Memberships
* Renew Memberships
* Cancel Memberships
* Track Membership Status

### Payment Management

* Record Payments
* View Payment History
* Track Pending Dues
* Multiple Installment Support

### Dashboard Analytics

* Total Members
* Total Plans
* Active Memberships
* Expired Memberships
* Revenue Tracking
* Pending Dues
* Expiring Membership Alerts

## Tech Stack

### Frontend

* React
* React Router
* Axios
* SCSS
* Vite

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

### Deployment

* Frontend: Vercel
* Database: MongoDB Atlas
* Image Uploads: ImageKit

## Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```
